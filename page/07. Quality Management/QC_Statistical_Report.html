Algorithms by Inspection Classification

The target elements vary by algorithm, and elements outside the inspection target are treated as not being targeted.

Inspection classification Target elements Algorithm description
Missing Value Check All observed data Check for error (-9999) values or missing values and treat as missing
Physical Limit Check Data with physical limit values set Values that do not fall within the standard thresholds set in the physical limit table are treated as errors
Step Check Instantaneous wind speed, 1-minute maximum wind speed, temperature, humidity, pressure, daily accumulated precipitation If the difference between the standard data 1-minute average value and the previous 1-minute average value exceeds the threshold, it is treated as a error, and if the previous 1-minute data is missing, it is treated as a missing threshold (in the case of wind speed, depending on the GUST status, it may be flagged as suspicious )
Persistence check Wind direction, wind speed, humidity, pressure Calculating the change amount between collected data within the standard persistence time from the last collection time, and treating as errors if it does not meet the minimum change amount criterion
Internal Consistency Check 1-minute average wind speed, 1-minute maximum wind speed When the 1-minute maximum wind speed is less than the 1-minute average wind speed, both the 1-minute wind speed and 1-minute maximum wind speed are treated as errors, and if the comparison target element observation value is missing, the element is treated as a missing threshold
Climate Range Check Temperature Values that do not fall within the monthly standard range are treated as errors
